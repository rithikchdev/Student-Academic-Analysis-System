# Student-Academic-Analysis-System
The Smart Student Performance Analytics System is a Java-based application designed to help educational institutions monitor, manage and analyze student academic performance. The system will maintain student information, subject details, marks, attendance and assessment records in a centralized database. 

For running it copy the source code and configure mysql database

.env file should look like this
DB_URL=jdbc:mysql://YOUR_HOST:YOUR_PORT/defaultdb?sslMode=REQUIRED
DB_USER=YOUR_USERNAME
DB_PASS=YOUR_PASSWORD

Running command: javac, java
Also download the JDBC from mysql website: https://dev.mysql.com/downloads/connector/j/
